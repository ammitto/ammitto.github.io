== Introduction

This is the Ammitto sanctions database website, located at https://www.ammitto.org.

It is a https://vuejs.org[Vue.js 3] application built with https://vitejs.dev[Vite] and https://vite-ssg.com[Vite SSG] for static site generation.

== Features

* **Sanctions Search Database** - Search across 55,000+ sanctioned entities from 14 publishing sources
* **Ontology Browser** - Explore the Ammitto knowledge graph schema
* **Lightweight Search** - Client-side FlexSearch over a compact index rather than the whole graph
* **Dark Mode** - Full dark mode support
* **Responsive Design** - Mobile-first design with Tailwind CSS

=== API Data

The website loads data from `public/api/v1/`:

[cols="1,2"]
|===
| File | Description

| `search-index.json` | Lightweight search index
| `facets/*.json` | Filter facet counts
| `ontology/classes.jsonld` | Ontology class definitions
| `ontology/properties.jsonld` | Ontology property definitions
| `ontology/hierarchy.json` | Class hierarchy tree
| `node/entity/{source}/{id}.jsonld` | Individual entity nodes
| `sources/{source}.jsonld` | Every entity and entry for one source
| `all.jsonld` | Complete knowledge graph
|===

=== Deployment

The site is automatically deployed to GitHub Pages via GitHub Actions.

The deployment workflow:

. Checks out the website repository
. Checks out the ammitto gem repository
. Clones the data-* repositories the workflow names
. Runs `ammitto harmonize` over the explicitly named sources to generate
  API data. They are listed rather than discovered with `--scan`, so that
  the harmonized source set stays exactly the set
  `.github/harmonize-thresholds.json` was calibrated against
. Builds the Vue.js application with Vite
. Deploys to GitHub Pages

To trigger a deployment:

[source,shell]
----
git push origin main
----

Or manually via GitHub Actions workflow dispatch.

== Data Sources

The 14 sources named in `publishing_sources` in
`.github/harmonize-thresholds.json` contribute entities to the site. A
fifteenth, `ru`, is harmonized but contributes none: `data-ru` ships no
processed YAML, so the deploy holds it at exactly zero entities and no
`sources/ru.jsonld` until its input returns. It still publishes its
vocabulary — the document types and organizations under
`sources/supporting/` are independent of the entity corpus — so it is listed
below because it is in the graph, not because it has entities.


[cols="1,1"]
|===
| Code | Authority

| au | Australia (DFAT)
| ca | Canada (SEFO)
| ch | Switzerland (SECO)
| cn | China (MOFCOM)
| eu | European Union
| eu_vessels | EU Vessels
| jp | Japan (MOFA)
| nz | New Zealand (MFAT)
| ru | Russia (MID) -- pending, no entities yet
| tr | Turkey
| uk | United Kingdom (OFSI)
| un | United Nations
| un_vessels | UN Vessels
| us | United States (OFAC)
| wb | World Bank
|===
